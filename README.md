# 📰 Fake News Detection

A Machine Learning-based Data Science project that automatically identifies and classifies news articles as **Fake** or **Real** using Natural Language Processing (NLP) and Machine Learning techniques.

The project uses **TF-IDF Vectorization** to convert news text into numerical features and compares two classification algorithms:

- Logistic Regression
- Passive Aggressive Classifier

The best-performing model is automatically selected and used for final prediction.

---

## 📌 Project Overview

Fake news and misleading information have become a major problem with the rapid growth of online news and social media platforms.

This project aims to build a machine learning system that can analyze the textual content of a news article and predict whether it is:

- ❌ **FAKE NEWS**
- ✅ **REAL NEWS**

The system performs data preprocessing, exploratory data analysis, feature extraction, model training, evaluation, and interactive prediction.

---

## 🎯 Objectives

The main objectives of this project are:

- Detect fake and real news articles automatically.
- Apply Natural Language Processing techniques to news text.
- Clean and preprocess raw textual data.
- Convert text into numerical features using TF-IDF.
- Train and compare multiple Machine Learning models.
- Evaluate models using accuracy and classification metrics.
- Provide an interactive predictor for new news articles.
- Visualize dataset characteristics and model performance.
